# Hi, I'm Devon Hill 👋

I'm a full-stack software engineer who enjoys building applications that solve real problems and create meaningful user experiences.

My current flagship project is **MySpanishDiary**, a full-stack web application that helps Spanish learners improve their writing by analyzing diary entries, identifying grammar mistakes, and providing contextual feedback. It's built with Spring Boot, React, PostgreSQL, JWT authentication, Spring Security, and LanguageTool.

I recently built my personal **developer portfolio** using Next.js, TypeScript, Tailwind CSS, shadcn/ui, and Framer Motion to showcase my projects, technical skills, and experience. I'm continuing to grow as a full-stack developer while exploring new ideas, including an AI-powered habit tracker called **Orbitual**.
